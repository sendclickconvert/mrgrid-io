# Dell "No Bootable Device" Error: Free Fix Guide

Your Dell displays "No Bootable Device Found." Before you pay $500 for repairs, try these free fixes.

## Check if Your Drive is Detected

1. Restart and tap F2 (or Delete) during boot
2. Enter BIOS setup
3. Look for your hard drive in Devices/Storage section
4. If it appears, the problem is software fixable

## Three Free Fixes That Work

### Fix 1: Switch Boot Mode
Enter BIOS, find Boot Mode, switch from UEFI to Legacy (or vice versa), save and restart.

### Fix 2: Fix Boot Sequence  
In BIOS Boot section, move your hard drive to position #1, save and restart.

### Fix 3: Reset BIOS
In BIOS, select Reset to Defaults, confirm, save and restart.

## Windows Recovery Option

If BIOS fixes don't work:
1. Download Windows Media Creation Tool
2. Create bootable USB on another computer
3. Boot from USB on your Dell
4. Select Repair Your Computer
5. Run Startup Repair

## When to Replace the Drive

Only if:
- Drive doesn't appear in BIOS after all fixes
- You hear clicking sounds from the drive
- Drive physically won't seat

## Cost Comparison

DIY hardware replacement: $50-150
Repair shop: $475-575
